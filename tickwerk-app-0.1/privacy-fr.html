Microphone

Tickwerk a besoin du microphone pour entendre le tic-tac de votre montre. Il n’est ouvert que pendant une mesure et se ferme aussitôt après. L’enregistrement reste dans la mémoire de travail du téléphone, y est analysé et n’est pas enregistré. Il ne quitte le téléphone que si vous le transmettez vous-même à une autre app avec « Partager l’enregistrement ».

En mode réglage, Tickwerk ne garde que les dernières secondes en mémoire de travail et n’enregistre rien. Si vous cherchez les microphones sous « Réglages », Tickwerk demande leur liste au navigateur ; les noms restent sur le téléphone, seul votre choix est enregistré.

Ce qui est enregistré sur le téléphone

Vos montres, les mesures (marche, défaut de repère, amplitude, fréquence, position, date, qualité du signal, une bande papier réduite), vos comparaisons de l’heure pour la marche au porté et les réglages se trouvent dans la mémoire de l’app sur votre téléphone. Personne d’autre que vous n’y a accès, pas même nous.

Tickwerk tient aussi un petit journal des erreurs : les 20 dernières erreurs avec leur date (par exemple « Le microphone n’a pas pu être ouvert »), sans nom de montre ni de fichier. Il reste lui aussi sur le téléphone. Sous Plus → « Partager le diagnostic », Tickwerk l’affiche sous forme de texte, avec des indications sur la version, l’appareil, le microphone, l’étalonnage et les dernières valeurs mesurées ; ce texte ne quitte le téléphone que si vous le partagez ou le copiez vous-même.

Vous pouvez tout supprimer sous Plus → Réglages → « Supprimer toutes les données ». Les données se trouvent dans la mémoire que Chrome tient pour Tickwerk. Si vous désinstallez l’app, elles y restent jusqu’à ce que vous supprimiez les données de site de Tickwerk dans Chrome. À l’inverse, si vous supprimez toutes les données de site dans Chrome, vos montres et vos mesures disparaissent aussi. Une sauvegarde vous en protège.

Tickwerk crée sur votre téléphone une sauvegarde (« Enregistrer une sauvegarde »), le rapport de mesure (PDF), un tableau des mesures (CSV), une image d’un résultat (« Partager en image ») et un fichier calendrier (.ics). Ce qu’il advient ensuite de ces fichiers, c’est vous qui décidez.

Rappels dans l’agenda

Si vous touchez « Google Agenda » pour un rappel, Google Agenda s’ouvre avec un rendez-vous préparé. Le titre (avec le nom de la montre), l’heure et un court texte sont alors transmis à Google, selon les conditions et la politique de confidentialité de Google. Sans votre geste, rien n’est envoyé à Google. Tickwerk crée le « fichier calendrier » sur le téléphone, sans internet.

Heure exacte d’Internet

L’horloge du téléphone peut s’écarter jusqu’à environ deux secondes. Pour la « Marche au porté », Tickwerk peut donc demander l’heure exacte sur Internet. Tickwerk vous le demande d’abord ; sans votre accord, cela n’a pas lieu, et vous pouvez le désactiver à tout moment sous Plus → Réglages.

Lors d’une requête, quelques demandes vides sont envoyées à GitHub Pages (GitHub Inc., USA), le prestataire qui héberge aussi les fichiers de l’app. Comme lors du chargement de l’app, il voit l’adresse IP de votre téléphone, l’heure et le type de navigateur. Rien n’est transmis sur vous, vos montres ou vos mesures. Les requêtes n’ont lieu que tant que la page « Comparaison de l’heure » est ouverte.

Signaler un modèle

Si vous touchez « Modèle manquant ? Le signaler » dans la recherche, Tickwerk ouvre votre messagerie avec un texte préparé (modèle, mouvement, source, version de l’application). Rien n’est envoyé avant que vous n’y touchiez Envoyer. Nous recevons alors votre adresse e-mail et le texte et ne les utilisons que pour compléter le catalogue et vous répondre.

Pas de publicité, pas d’analyse

Tickwerk n’utilise ni cookies, ni services de publicité ou d’analyse, ni polices ou scripts de serveurs tiers. Il n’y a pas de compte utilisateur.

Chargement de l’app

Les fichiers de l’app sont hébergés chez GitHub Pages (GitHub Inc., USA). Lors du chargement et des mises à jour, ce prestataire traite les données techniquement nécessaires, comme l’adresse IP, l’heure et le type de navigateur, pour livrer les fichiers et empêcher les abus. Ensuite, Tickwerk fonctionne aussi sans internet.
